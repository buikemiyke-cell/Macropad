# Macropad
10 Key macropad with programmable OLED display and rotary encoder for volume
I added one thumb key because it was originally intended for gaming, and the oled screen was added to make it look less boring. I got help from the macropad slack channel and various guides online especially from @joe_scotto on Youtube
